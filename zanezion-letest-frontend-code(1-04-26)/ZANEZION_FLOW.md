# 🏛️ ZaneZion Institutional — The Master Operating Protocol (v4.0)

> **ZaneZion Platinum Network** ek ultra-luxury ecosystem management platform hai.  
> Is document mein onboarding se lekar final audit tak ka **Complete Detailed Flow** aur sabhi **8 Dashboards** ke har ek menu ki **Functional Working** documented hai.

---

## 🔱 1. SUPER ADMIN DASHBOARD (The Central Intelligence)
*System ka 'God-Mode' jahan se poore platform ki health control hoti hai.*

- **Dashboard (Overview)**: Global statistics ka live snapshot. Active Missions, Total Revenue (Invoiced vs Collected), Pending SaaS Requests, aur Stock Alerts ek hi screen par dikhte hain.
- **Clients (Institutional Registry)**: Saare onboarded clients ki list. Naye clients add, plan manage (Platinum/Executive), aur status toggle.
- **Vendors (Supply Chain Partners)**: Caribbean ke luxury suppliers ka database. Rating, delivery performance, aur contact history.
- **Purchase Orders (Institutional Sourcing)**: Admin vendors ko official PO issue karta hai. **Ab ek PO mein multiple line items support hain (Item Name, Qty, Price, Category).** 'Receive Goods' terminal se har item ki **Partial Delivery** track hoti hai.
- **Orders & Missions (Command Center)**: Har naya client order 'Pending' dikhta hai. Missions launch aur Operations ko pass.
- **Inventory (Global Stock)**: **Inventory ab do categories mein separated hai: Marketplace Inventory aur Client Inventory. Dono ka data alag store hota hai.** Admin portal mein dedicated tabs hain switching ke liye. Stock Entry ke waqt "Client Owner" assign karne ka option hai.
- **Staff Management (Human Assets)**: Har staff member ka profile, role, **phone number**, aur authentication. **Task Delegation tab se staff ko directly tasks assign karna (priority + deadline + status tracking). Missions tab mein live mission ledger.**
- **Invoices (Financial Ledger)**: Create Invoice, payment track, status manage (Due/Paid/Overdue).
- **Payroll (Institutional Salary)**: Net pay calculate. NIB deductions, medical insurance, overtime.
- **Reports (Deep Analytics)**: Financial records aur mission success rates export.
- **SaaS Management (Onboarding Terminal)**: Nayi companies ki onboarding queue.
- **Support Dashboard (Ticketing)**: Client issues resolve karna.
- **Chauffeur Requests (Admin View)**: Saare incoming chauffeur bookings ek jagah dekho aur manage karo.
- **Staff Terminal (Mirror View)**: Admin ko field staff ka interface dikhta hai.
- **Settings (Global Protocols)**: White-label branding, delivery pricing, encryption keys.

## 🔄 END-TO-END OPERATIONAL FLOW (Master Sequence v4.0)

1. **Onboarding Cycle**:
   - Nayi SaaS Company register karti hai.
   - Admin `SaaS Management` se approve karta hai.
   - Client `Settings` mein jaakar Branding set karta hai → **Pure White-label Portal.**

2. **Order Lifecycle**:
   - Client `Marketplace` se order karta hai.
   - Status **`Pending Review`** banta hai.
   - Super Admin usey **`Approved`** karta hai.
   - Operations manager Mission launch karke **Logistics Protocol** assign karta hai.

3. **Fulfillment Cycle (Dual Mission Types)**:
   - Operations → Deliveries mein **Mission Type** choose karo:
     - **Chauffeur Mission**: Passenger Name, Pax Count, Pickup Area, Drop Location, Luggage.
     - **Logistics Mission**: Pickup Location, Package Weight, Item Description.
   - **Request Date** auto-captured; **Event Date** manually schedule karo.
- **Inventory Separation**: Marketplace inventory automatic client inventory mein nahi aayegi. Logistics dispatch ke waqt categories check ki jaati hain.
- **Logistics Dispatch**: Multi-item rows add karne ka option "**ADD ASSET**" button ke through Operations portal mein enable kar diya gaya hai.
- **Dimensions Protocol**: Optional Length, Width, Height fields ab mission manifest mein integrated hain.
- **Field Staff update deta hai**: **Accepted → En Route → Delivered**.
- Delivery par **Signature + Photo** capture hota hai.

4. **Procurement & Sourcing Cycle (PO System)**:
   - Stock kam hone par PR generate hota hai.
   - Vendor quotes approve → **Purchase Order (PO)** issue.
   - Goods receive → `Receive Goods Against PO` terminal par qty entry.
   - Status **`Partially Received`** ya **`Completed`** → **Stock Levels auto-sync.**

5. **Chauffeur Protocol Sequence**:
   - Client `Book Chauffeur` se request submit (One Way/Round Trip/Daily).
   - Fields dynamically change based on service type.
   - Concierge `Chauffeur Management` mein security vetting.
   - **`Confirmed`** hote hi logistics dispatch.

6. **Super Admin Task Delegation**:
   - Admin `Staff Management → Delegate Task` click karta hai.
   - Staff member, task description, location, priority (Low/Medium/High/Critical) set.
   - Task auto-generates with `requestDate` aur `Pending` status.
   - Staff ke `My Assignments` mein appear hota hai.
   - Staff status update karta hai → Admin **Missions Tab** mein live track.

7. **Staff Leave Cycle**:
   - Staff `Leave & Absence` se request submit karta hai.
   - Admin `Staff Management → Leave Tab` mein approve/reject karta hai.
   - Status real-time reflect hota hai.

8. **Financial Cycle**:
   - Delivery complete hote hi Invoice generate hoti hai.
   - Client payment karta hai → Admin Dashboard par revenue reflect.
   - Staff ka pay record `Pay & Records` tab mein auto-log.

## 🛠️ TECHNICAL CONNECTIVITY (Zero-Gaps)
- **Data Sync**: Sabhi dashboards ka data `GlobalDataContext.jsx` se single source of truth leta hai.
- **Mission Types**: `missionType` field Deliveries mein Chauffeur vs Logistics differentiate karta hai.
- **Date Tracking**: `requestDate` = auto-captured creation date; `eventDate` = schedulable execution date.
- **PO System**: `addPurchaseOrder` → `receiveGoodsAgainstPO` → `addStockEntry` auto-chain.
- **Task Delegation**: `addStaffAssignment` function context se expose ho raha hai.
- **Security**: `App.jsx` roles strictly monitor karta hai.
- **Staff Phone**: `phone` field users context mein add hai aur form mein visible.
